## وش فيه؟

### 🔎 Nexa Search: بحث داخل الملفات
- تكتب جملة تتذكرها من **داخل** الملف، أو جزء من اسم ملف أو مجلد، والأداة تلقاه.
- يقرأ Word وPowerPoint وExcel وPDF والنصوص والكود، بالعربي والإنجليزي (ويتجاهل أ/ا و ة/ه والتشكيل).
- فلترة بالنوع (ملفات / مجلدات) وترتيب بالأحدث، و«بحث عميق» يلقى الكلمة حتى لو ملصوقة بحرف (ومحمد، لمحمد).

### 📝 Nexa Notes: سبورات ملاحظات عائمة
- كل ملاحظة سبورة **Excalidraw**: رسم حر، أشكال، أسهم، نصوص، صور.
- 🎙 تسجيل صوتي، و🎙 تسجيل مع **تحويل الصوت لنص** (يدعم العربي).
- تقفل الملاحظة فتصير أيقونة صغيرة بنفس مكانها على سطح المكتب، وتضغطها ترجع تفتح.

### ⌨️ اختصارات من أي مكان
| الاختصار | يسوي |
|---|---|
| اضغط **Space** واستمر عليه، ثم **F** | يفتح البحث |
| اضغط **Space** واستمر عليه، ثم **N** | ملاحظة جديدة عند الماوس |

## التثبيت
1. نزّل **`NexaTools-Setup-….exe`** من [الإصدارات](https://github.com/M7md3rb/nexa-tools/releases/latest) وشغّله. ما يحتاج صلاحيات مدير.
2. لو طلعت رسالة **«Windows protected your PC»** (لأن البرنامج جديد وغير موقّع): اضغط **More info** ← **Run anyway**.
3. أول تشغيل يجهّز كل شي لحاله: الاختصارات، فهرسة ملفاتك بالخلفية، وتشغيل الملاحظات مع ويندوز.

تبغاه بدون تثبيت؟ نزّل **`NexaTools-Portable-….zip`** وفكّه وشغّل `NexaTools.exe`.

## أوامر للمتقدمين
داخل مجلد البرنامج يوجد `nexa.exe`:
```
nexa find "جملة من داخل الملف"
nexa config add-drives      # فهرسة كل الأقراص
nexa index
nexa doctor                 # فحص الإعداد
```

## الخصوصية
كل شي يصير على جهازك: الفهرس والملاحظات والتسجيلات. ما في أي حساب أو سيرفر أو تتبّع. الإنترنت يُستخدم مرة وحدة بس، لتنزيل موديل تحويل الصوت لنص أول ما تستخدمه.

## إزالة
من إعدادات ويندوز ← التطبيقات ← Nexa Tools ← إلغاء التثبيت. ملاحظاتك تبقى في مجلد المستندات.
